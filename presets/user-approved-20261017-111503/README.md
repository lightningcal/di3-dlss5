# User-approved ReShade settings

Snapshot of the active DI3 preset, main ReShade configuration, Feeder configuration and x64 helper ReShade configuration. Relative paths mirror the game folder. File hashes are in manifest.json.

To restore: close Disney Infinity and its DLSS helper; back up the current versions of these four files, then copy the snapshot files to their matching game-folder paths. Keep the existing mod, shader packages and DLLs installed; this snapshot contains settings only. Launch the game again. Main ReShade.ini selects mods/di3-dlss5/DI3-DLSS5.ini.

The NVIDIA driver background-cap setting is separate and is not included in this file snapshot. Keep Global Background Application Max Frame Rate Off for the verified removal of the 30 FPS ceiling.
